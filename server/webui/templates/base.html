วิธีติดตั้ง Agent

ติดตั้ง monitor-agent.exe บนเครื่องที่ต้องการ monitor แล้วรัน (ไฟล์ config/data อยู่ข้าง exe ไม่ต้องมี Python):

1. ระบุ host_id แล้วสร้าง token (แสดงครั้งเดียว) — agent จะส่งข้อมูลภายใต้ host นี้
2. คัดลอกคำสั่ง แล้วรันบนเครื่องเป้าหมาย (Windows — Linux ใช้ ./monitor-agent)
monitor-agent.exe --install --server http://127.0.0.1:18080 --token <TOKEN> --interval 15 [--ports 80:web,443:https] [--watch nginx]

เพิ่มเครื่องใหม่ (Agent)

กำหนดค่า agent สำหรับเครื่องใหม่ แล้วคัดลอกคำสั่งไปรันบนเครื่องนั้น (ไม่ต้องมี Python — ไฟล์ config/data อยู่ข้าง exe)

token: สร้างโดยอัตโนมัติจาก host_id (แสดงครั้งเดียว)
ยังไม่สร้าง token
คำสั่งติดตั้ง:
monitor-agent.exe --install --server <URL> --token <TOKEN> --interval 15 ...
