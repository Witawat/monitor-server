การแจ้งเตือน (Webhook / Telegram)

ตั้งค่าช่องทางรับการแจ้งเตือน alert — บันทึกแล้วมีผลทันที (ไม่ต้อง restart server)

Webhook —

POST JSON เมื่อ alert trigger (ใช้กับ Slack / Teams / บริการอื่น)

Telegram —

ส่งข้อความตรงถึงบอทของคุณเมื่อ alert trigger

  1. ใน Telegram ค้นหา @BotFather → สร้างบอทด้วย /newbot → ได้ Bot Token
  2. แชทกับบอทของคุณ (กด Start) เพื่อสร้าง chat
  3. หา Chat ID: ส่งข้อความไปบอท แล้วเปิด https://api.telegram.org/bot<TOKEN>/getUpdates ในเบราว์เซอร์ → อ่านค่า "chat":{"id": ... (ห้องกลุ่มให้ติดเครื่องหมายลบ เช่น -100123456789)
